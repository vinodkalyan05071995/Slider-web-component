slider-element examples

Each page is standalone, so you can view its source and copy the markup. Serve the repo root with any static server, e.g. python3 -m http.server.

  • Basic — One slide at a time with arrows, pagination, drag/swipe and keyboard. No options needed.
  • Loop & rewind — loop wraps around seamlessly. rewind jumps back to the first slide after the last one.
  • Responsive (breakpoints) — Mobile-first min-width breakpoints change perView, perMove and gap. A fractional per-view lets the next slide peek in. Resize the window to see it change.
  • Autoplay — autoplay="3000" sets the interval in ms. It adds a play/pause button, pauses on hover, stops when keyboard focus enters, and doesn't start for users who prefer reduced motion.
  • Fade transition — transition="fade" cross-fades slides. speed sets the duration in ms.
  • Thumbnails — A second slider with nav-for="gallery" becomes the thumbnail navigator for the slider with id="gallery".
  • Right-to-left — Picked up automatically from dir="rtl" on the page or a parent element (or set direction="rtl"). Arrows, drag and arrow keys follow the reading direction.
  • Vertical — direction="ttb" slides top to bottom. Give it a height (any CSS length; it can change per breakpoint). Use the Up/Down arrow keys or drag vertically.
  • JavaScript API & events — Drive the slider from your own controls and listen for slide-change.
  • Translations — Override SliderElement.i18n before any slider is created: load the script without defer and set the strings right after it (or set them before your deferred bundle defines the element). %s placeholders are filled in order.
  • Theming — Restyle with CSS custom properties and the .slider-element__* / .is-* class hooks.
  • Shopify section — a theme section with blocks, thumbnails and schema settings (Liquid source).
